# CogniStream

**Developer Flow-State & Cognitive Load Analytics**

CogniStream is a data engineering and analytics platform that helps organizations understand developer productivity by analyzing focus time, interruptions and context switching instead of relying only on traditional metrics like commits or lines of code.

## Project Status

🚧 Under Development

## Tech Stack

- Frontend: React + TypeScript + Tailwind CSS + Tremor
- Backend: Python + FastAPI
- Analytics: Polars
- Database: ClickHouse
- Workflow Orchestration: Apache Airflow
- Version Control: Git + GitHub
